# Khmer text review

Every Khmer string in Prasat beside its English, for a native speaker to check. The strings live in
`i18n/locales/km.json`; settings and install prompts are shared with the other games and reviewed there.

Worth a second look: the temple names, ជាន់ for a floor of the tower, ល្អឥតខ្ចោះ for a perfect drop, and how
Sophal and Master Prom (លោកគ្រូ/ក្មួយ) speak.
